About BeyondBench

BeyondBench introduces a revolutionary approach to evaluating reasoning capabilities in language models without relying on traditional static benchmarks. Our system dynamically generates novel problems across 44 distinct reasoning tasks with 117 variations, ensuring that models cannot memorize solutions and must demonstrate true reasoning abilities.

🔍 Key Insights

  • Reasoning Gap: Even the best models show significant performance drops on harder reasoning tasks
  • Scaling Effects: Larger models generally perform better, but the relationship is not always linear
  • Instruction Following: High accuracy doesn't always correlate with instruction-following compliance
  • Token Efficiency: Some models achieve comparable accuracy with significantly fewer tokens
  • True Reasoning: Dynamic generation reveals genuine capabilities vs. memorization

Getting Started

Installation

pip install beyondbench

Or install from source for the latest features:

git clone https://github.com/ctrl-gaurav/BeyondBench.git
cd BeyondBench
pip install -e .

Quick Start (CLI)

# List all available tasks
beyondbench list-tasks

# Run evaluation on a model
beyondbench evaluate \
  --model-id meta-llama/Llama-3-8B-Instruct \
  --suite all \
  --backend vllm \
  --datapoints 100

Quick Start (Python API)

from beyondbench import EvaluationEngine, TaskRegistry

# Initialize engine
engine = EvaluationEngine(
    model_id="meta-llama/Llama-3-8B-Instruct",
    backend="vllm"
)

# Run evaluation
results = engine.evaluate(suite="all")
print(results)

Evaluation Backends

BeyondBench supports multiple inference backends. Choose the one that best fits your setup.

vLLM

High-throughput inference with PagedAttention. Best for local GPU evaluation of open-source models.

beyondbench evaluate \
  --model-id meta-llama/Llama-3-8B-Instruct \
  --backend vllm \
  --tensor-parallel-size 2 \
  --gpu-memory-utilization 0.95 \
  --suite all --datapoints 100

Transformers

HuggingFace Transformers for flexible local inference. Great for debugging and smaller models.

beyondbench evaluate \
  --model-id microsoft/phi-3-mini-4k-instruct \
  --backend transformers \
  --cuda-device cuda:0 \
  --trust-remote-code \
  --suite easy --datapoints 50

OpenAI API

Evaluate GPT-4, GPT-4o, o1, o3, and other OpenAI models via their API.

# Set API key
export OPENAI_API_KEY="sk-..."

beyondbench evaluate \
  --model-id gpt-4o \
  --api-provider openai \
  --reasoning-effort medium \
  --suite all --datapoints 100

Google Gemini API

Evaluate Gemini Pro, Gemini Ultra, and Gemini Flash models via Google's API.

# Set API key
export GEMINI_API_KEY="AI..."

beyondbench evaluate \
  --model-id gemini-2.0-flash \
  --api-provider gemini \
  --thinking-budget 1024 \
  --suite all --datapoints 100

Anthropic API

Evaluate Claude 3.5, Claude 4, and other Anthropic models via the Anthropic API.

# Set API key
export ANTHROPIC_API_KEY="sk-ant-..."

beyondbench evaluate \
  --model-id claude-sonnet-4-20250514 \
  --api-provider anthropic \
  --suite all --datapoints 100

Task Suites

44 dynamically generated reasoning tasks across 3 difficulty levels with 117+ variations. Every evaluation instance is unique.

Easy

29 Tasks

Core mathematical and list-processing reasoning

  • Arithmetic: Sum, Subtraction, Multiplication, Division
  • Statistics: Mean, Median, Mode, Range
  • Search: Find Min/Max, Second Max, Index of Max
  • Counting: Even/Odd, Negatives, Palindromes, Perfect Squares, Multiples, Unique
  • Advanced: Sorting, LIS, Adjacent Diff, Local Maxima, Alternating Sum
beyondbench evaluate --model-id MODEL --suite easy
Medium

5 Tasks · 49 Variations

Pattern recognition and sequence reasoning

  • Algebraic Sequences (linear, quadratic, polynomial)
  • Fibonacci Variants (classic, tribonacci, custom rules)
  • Geometric Sequences (ratios, decay, growth)
  • Prime Number Sequences (twin primes, prime gaps)
  • Complex Patterns (interleaved, recursive, multi-rule)
beyondbench evaluate --model-id MODEL --suite medium
Hard

10 Tasks · 68 Variations

Combinatorial optimization and constraint satisfaction

  • Sudoku Solving (4x4, 6x6, 9x9)
  • N-Queens Problem (4-8 queens)
  • Graph Coloring (3-5 colors)
  • Boolean Satisfiability (SAT)
  • Cryptarithmetic, Tower of Hanoi, Matrix Chain, Constraint Optimization
  • Modular Systems, Logic Grid Puzzles
beyondbench evaluate --model-id MODEL --suite hard

Advanced Usage

Generation Parameters

# Fine-tune generation behavior
beyondbench evaluate \
  --model-id MODEL \
  --temperature 0.3 \
  --top-p 0.95 \
  --max-tokens 1024 \
  --seed 42 \
  --batch-size 8

Custom Evaluation Scope

# Evaluate specific tasks only
beyondbench evaluate \
  --model-id MODEL \
  --tasks sum_task sorting_task \
  --datapoints 200 \
  --folds 3 \
  --store-details

Scalable Tasks

# Test with varying list sizes
beyondbench evaluate \
  --model-id MODEL \
  --list-sizes "8,16,32,64,128" \
  --range-min -1000 \
  --range-max 1000 \
  --suite easy

Output & Logging

# Control output and logging
beyondbench evaluate \
  --model-id MODEL \
  --output-dir ./my_results \
  --store-details \
  --log-level DEBUG \
  --max-retries 5 \
  --timeout 600

Multi-GPU Setup

# Use tensor parallelism for large models
beyondbench evaluate \
  --model-id meta-llama/Llama-3-70B-Instruct \
  --backend vllm \
  --tensor-parallel-size 4 \
  --gpu-memory-utilization 0.90

Python API - Full Control

from beyondbench import EvaluationEngine
from beyondbench.core.task_registry import TaskRegistry

# List available tasks
registry = TaskRegistry()
tasks = registry.get_available_tasks()
stats = registry.get_suite_stats()

# Configure and run
engine = EvaluationEngine(
    model_id="gpt-4o",
    api_provider="openai",
    temperature=0.3,
    max_tokens=1024
)
results = engine.evaluate(
    suite="hard",
    datapoints=100,
    store_details=True
)
