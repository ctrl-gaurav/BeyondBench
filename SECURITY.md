# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x.x (latest) | Yes       |
| older releases  | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in BeyondBench, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email **gks@vt.edu** with the following details:

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours of your report.
- **Initial assessment**: Within 1 week.
- **Fix or mitigation**: Depending on severity, typically within 2-4 weeks.

We appreciate your help in keeping BeyondBench secure.
